# Visualization data

`web_data/umap_data.json` and `web_data/umap_data.csv` contain the same paired
HERMIT visualization dataset:

- 30,000 unique cell identifiers;
- RNA, 5hmC, and 5mC for every identifier;
- 90,000 modality points in total;
- UMAP coordinates and modality-specific subclass annotations.
